Build a personal expense tracker. Users register, sign in and record expenses (amount, category, date, description), then filter them by category and period and see totals per category.

Endpoints: POST /api/auth/register, POST /api/auth/login, GET /api/expenses, POST /api/expenses, GET /api/expenses/summary, GET /api/expenses/{id}, PUT /api/expenses/{id}, DELETE /api/expenses/{id}.
