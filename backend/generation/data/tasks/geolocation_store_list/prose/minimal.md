Build a store finder. Anyone can browse and search store locations and find the stores nearest to a point within a radius, with their distance. The admin adds, edits and deletes stores.

Endpoints: POST /api/auth/register, POST /api/auth/login, GET /api/stores, GET /api/stores/{id}, POST /api/admin/stores, PUT /api/admin/stores/{id}, DELETE /api/admin/stores/{id}.
