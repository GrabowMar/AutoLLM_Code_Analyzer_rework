Build a shared kanban board with three columns: To Do, In Progress and Done. Anyone views the board; signed-in users create tasks, edit them, drag them between and within columns, and delete them.

Endpoints: POST /api/auth/register, POST /api/auth/login, GET /api/tasks, POST /api/tasks, GET /api/tasks/{id}, PATCH /api/tasks/{id}, DELETE /api/tasks/{id}.
