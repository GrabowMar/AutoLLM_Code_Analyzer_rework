Build a shared customer directory for a team. Signed-in members add, edit, search and delete customer contacts and log calls, emails and meetings per customer. Visitors see only a sign-in screen.

Endpoints: POST /api/auth/register, POST /api/auth/login, GET /api/customers, POST /api/customers, GET /api/customers/{id}, PUT /api/customers/{id}, DELETE /api/customers/{id}, GET /api/customers/{id}/interactions, POST /api/customers/{id}/interactions.
