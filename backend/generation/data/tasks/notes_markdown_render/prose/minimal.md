Build a Markdown notes app. Users write notes in Markdown, edit and delete them, and read them rendered as HTML with headings, lists, links, images and code blocks. A note can be published so anyone can read its rendered page.

Endpoints: POST /api/auth/register, POST /api/auth/login, GET /api/notes, POST /api/notes, GET /api/notes/{id}, PATCH /api/notes/{id}, DELETE /api/notes/{id}, GET /api/notes/{id}/html, GET /api/public/notes/{id}/html.
