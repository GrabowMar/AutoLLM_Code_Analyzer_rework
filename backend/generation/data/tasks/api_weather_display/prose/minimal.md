Build a weather display that serves current weather from the app's own store of city reports, without calling any outside service. Anyone can look up a city and see recent lookups; signed-in users add, replace and delete reports.

Endpoints: POST /api/auth/register, POST /api/auth/login, GET /api/weather, POST /api/weather, GET /api/weather/{id}, PUT /api/weather/{id}, DELETE /api/weather/{id}, GET /api/weather/recent.
