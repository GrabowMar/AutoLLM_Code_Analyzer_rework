Build an XML well-formedness checker. Anyone pastes a document and learns whether it is well-formed, and if not, the first error with its line and column; signed-in users save checks to a private history and filter or delete them.

Endpoints: POST /api/auth/register, POST /api/auth/login, POST /api/validate/xml, POST /api/validations, GET /api/validations, DELETE /api/validations/{id}.
