Build a shared book catalogue. Anyone can browse and search books and read reviews; signed-in users add, edit and delete books and post one rating with an optional comment per book.

Endpoints: POST /api/auth/register, POST /api/auth/login, GET /api/books, POST /api/books, GET /api/books/{id}, PUT /api/books/{id}, DELETE /api/books/{id}, GET /api/books/{id}/reviews, POST /api/books/{id}/reviews.
