Build a shared event calendar. Anyone browses upcoming events in day, week and month views; signed-in users create, edit and delete events with a title, start and optional end time, location and description.

Endpoints: POST /api/auth/register, POST /api/auth/login, GET /api/events, POST /api/events, GET /api/events/{id}, PUT /api/events/{id}, DELETE /api/events/{id}.
