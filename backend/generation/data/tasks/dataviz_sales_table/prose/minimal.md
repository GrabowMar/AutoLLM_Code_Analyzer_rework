Build a sales dashboard. Anyone can explore recorded sales as a table, headline totals (sum, count, average) and a daily bar chart, filtered by date range and product; signed-in users add, edit and delete sales.

Endpoints: POST /api/auth/register, POST /api/auth/login, GET /api/sales, POST /api/sales, GET /api/sales/summary, GET /api/sales/daily, GET /api/sales/{id}, PUT /api/sales/{id}, DELETE /api/sales/{id}.
