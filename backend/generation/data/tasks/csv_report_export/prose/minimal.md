Build a personal timesheet. Users log time entries (project, description, hours, date), filter them by period and project, see totals per project, and download their entries or the per-project totals as CSV files for spreadsheets.

Endpoints: POST /api/auth/register, POST /api/auth/login, GET /api/entries, POST /api/entries, PATCH /api/entries/{id}, DELETE /api/entries/{id}, GET /api/exports/entries.csv, GET /api/exports/summary.csv.
